# Security policy

## Supported version

The current `main` branch receives security fixes.
This project is research software and has not reached a stable release.

## Report a vulnerability

Use a private GitHub security advisory for this repository.
Do not open a public issue for a vulnerability that can expose another user or system.

Include the affected revision, impact, and a minimal reproduction.
Do not include credentials, session links, private data, or unrelated host information.
