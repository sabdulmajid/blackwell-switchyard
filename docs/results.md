# Operator results

Generated by `scripts/summarize_operator.py` from `results/operator_*.json`.
Every figure below comes from those files; none is typed by hand.

**Measurement.** Median of 100 CUDA-event-timed repetitions after 25 warmup
iterations, with the 128 MiB L2 flushed between repetitions. Compilation and
autotuning happen before timing and are reported separately in the JSON. Every
implementation is checked against a float64 oracle before it is timed; anything
that fails is excluded rather than reported.

**Speed of light** is a Triton kernel that touches exactly the operator's bytes
with the same access pattern, tile shape and launch geometry, but skips the
softmax. No correct implementation can beat it, which makes it a fairer ceiling
than a generic copy benchmark.

**Environment.** NVIDIA RTX PRO 6000 Blackwell Max-Q Workstation Edition (CC 12.0), torch 2.9.0+cu128+cu12.8, triton 3.5.0, bf16.
